# WP-03B saved-session catalog evidence

**Date:** 2026-10-23

**Branch:** `dev-1`

**Requirements:** F-004 (partial), P-13 (partial), P-38 (catalog count behavior only).

## Scope

The workbench can explicitly save the active local shell or SSH endpoint, search saved names and hosts, mark favorites, reopen definitions and delete them. Typed validated commands cross preload IPC; the SQLite catalog shares the storage utility worker with host trust. Definitions contain only the local shell or canonical SSH host/port plus a user-supplied name and catalog metadata. Credentials, connection secrets and terminal history are not persisted.

The catalog UI extends the established slate workbench rail with a search field, compact definition rows, separate favorite/delete controls, an empty state, a focused save dialog, keyboard focus containment and focus return. Saved SSH definitions use the existing explicit host-verification and credential-entry path when opened.

No schema version or dependency changed. No ADR was needed. F-004 and P-13 remain `PLANNED`: folder CRUD/cycle detection and full acceptance are not complete.

## Findings fixed during validation

The storage worker initially posted catalog repository Promises instead of awaiting them. Electron could not structured-clone those values, and the worker's non-throwing send helper left requests pending until timeout. The worker now awaits each catalog operation before posting its result; the focused worker and workbench E2E paths pass.

Independent review found that catalog busy/corrupt errors lost their category at the worker boundary, catalog calls had no cancellation token, timed-out IPC calls could continue in the background, saved IPv6 endpoints were rendered without brackets, and the uncertain-save dialog did not enforce checking before retry. The worker now preserves storage error kinds; catalog cancellation flows through the application and adapter ports on renderer destruction, renderer crash, or a validated preload timeout request that waits for main-process cancellation to settle; and saved SSH rows use the shared IPv6-safe endpoint label. An uncertain save retains its exact draft across closing or reopening the dialog, focuses the available check action and blocks retries until a successful filtered catalog check confirms whether that definition exists. Focused unit tests cover cancellation forwarding, authorized cancellation request validation, timeout notification and worker error-category mapping. A Windows E2E covers a committed write with a delayed reply, cancellation settlement, dialog dismissal/reopening and catalog reconciliation.

## Limits

Folders, parent-cycle prevention, settings, catalog import/export and corruption recovery remain planned. The 1,002-item scale check is a repository test; the E2E checks use a small catalog and do not measure the 150 ms search target. Reopening a saved local terminal is E2E-tested. Saved SSH metadata is round-tripped through the storage worker, but an SSH reconnect against a disposable OpenSSH fixture has not been verified; `pnpm test:ssh-fixture` was not run because no fixture is configured. The product still has no standalone installer or portable `.exe` package.
