## Limits

No OpenSSH server executable or `sshd` service is installed on this machine, and the local Docker engine is stopped. No real SSH handshake, password authentication, host-key rotation, or native credential dialog was exercised end to end. Application tests cover unknown-host approval, rejection/cancellation, reset-and-approve flow and changed-key blocking with fakes; they do not substitute for the required disposable OpenSSH fixture.

This slice supports password authentication only and prompts for credentials on each explicit quick-connect action. It does not yet resolve saved `credential_ref` values through the vault; saved-credential reuse is tracked for the session-catalog slice. Private-key authentication, agent authentication, SFTP and forwarding are outside this slice. P-03/F-003 and every feature-matrix entry remain `PLANNED` until the Windows OpenSSH acceptance cases pass.
