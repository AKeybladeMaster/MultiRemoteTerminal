# WP-03C saved-session folders evidence

**Date:** 2026-10-23

**Branch:** `dev-1`

**Requirements:** F-004 (partial), P-13 (partial).

## Scope

Saved definitions can be organized in nested folders through the workbench. Users can create, rename, move and delete folders; move saved sessions between folders; search saved sessions; and reopen them after moving or restarting the application. Deleting a folder safely promotes its direct child folders and all saved-session kinds into the deleted folder's parent. If promotion would create a sibling-name conflict, the transaction rolls back without losing definitions.

The SQLite repository rejects parent cycles and case-insensitive duplicate folder names within a parent. Typed, validated commands connect the renderer to the existing storage worker through preload IPC. The schema already contained the needed folder fields and tables, so this phase adds no migration or package.

## Findings fixed during validation

The action panels for saved sessions and folders were clipped by the sidebar's scrolling list near its lower edge, which blocked browser clicks. The native disclosure control now toggles and synchronously positions its action panel in the viewport, opening upward when space below is insufficient. The focused and full Windows E2E flows verify these actions. A `content-visibility` experiment also interfered with sidebar hit testing and was removed.

## Review notes

Independent spec review found no Critical or Important issue and confirmed the partial/planned status wording. Standards review found no documented-standard breach. It recorded one Minor judgement call: dialog Tab-cycle logic is repeated in the renderer, and folder descendant traversal exists both in the UI and SQLite. The repeated focus loop is small and the dialogs use different focusable controls; the UI traversal hides invalid move targets while SQLite independently rejects cycles, so both safeguards remain. Revisit a shared focus helper if further dialogs make the repetition harder to maintain.
