# WP-01 Windows acceptance result

**Status:** passed on 2026-10-23. This is evidence for the local tabbed-terminal workflow (P-01 / F-002), not for remote protocols, packaging, or release readiness.

## Environment

- Windows 11 Pro x64, build 26200
- Node.js 24.14.1 x64
- Electron pinned to 45.0.0
- ConPTY and the pinned `node-pty` prebuild loaded inside the Electron utility process

## Acceptance evidence

- `pnpm typecheck`: passed.
- `pnpm lint`: passed; static import-boundary check passed.
- `pnpm test`: 20 passed, 0 failed.
- `pnpm build`: passed. Vite reports a non-blocking 568 kB renderer chunk warning; gzip output is about 156 kB.
- `pnpm test:e2e`: 2 passed, 0 failed.
- Windows E2E uses a test-only 750 ms first-open reply barrier so the UI can cancel after a real PowerShell shell PID exists; it verifies that PID exits, then opens PowerShell and cmd, executes shell commands, pastes Unicode, resizes at 200% device scale, switches themes, navigates the palette and tabs by keyboard, opens 10 simultaneous tabs, and repeatedly closes sessions.
- The test collected the PIDs from 9 concurrent PowerShell sessions. After closing all 10 tabs and then 3 additional open/close cycles, `tasklist.exe` confirmed those PowerShell processes had exited.
- A separate live PowerShell's parent utility worker was terminated with `taskkill.exe`; the app reported the worker failure, confirmed the shell PID exited, and opened a new working session on a replacement worker.
- Unit tests cover cancellation while the application controller is still awaiting provider startup. The UI exposes a Cancel action while startup is pending, and late successful replies are closed to prevent a leaked session.
- Local shell resolution uses absolute paths under `SystemRoot\\System32`; a unit check covers PowerShell and cmd paths without `PATH` lookup.
- At 100% device scale, both themes and the viewport fit were checked and captured; the ten-tab workflow checks both themes at 200% device scale.
- Close confirmation, keyboard focus containment, cancellation with Escape, renderer isolation, IPC allowlisting, CSP, blocked file access, denied popups/navigation/permissions, and foreign-window IPC denial passed.
- `pnpm audit --prod`: no known vulnerabilities found.

The visual target and live captures are checked at 100% and 200% scale during E2E; generated run screenshots remain under ignored `test-results/` and are not committed because they include the current Windows account path.
