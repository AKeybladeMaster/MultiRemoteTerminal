# WP-03 storage phase evidence

**Date:** 2026-10-23

**Branch:** `dev-1`

**Scope:** first WP-03 storage phase; implements the ADR-0003 host-key migration into the versioned SQLite schema. This does not complete session catalog CRUD or change P-13/F-004 status.

## Verification

- `corepack pnpm check` passed after review fixes: TypeScript, ESLint and import boundaries; 73 unit tests; Windows x64 build; 6 Electron E2E tests.
- `corepack pnpm test:ssh-fixture` was skipped because no disposable OpenSSH server and credentials were configured.
- SQLite unit coverage verifies schema creation and repeat migration, allowed session kinds, insert/match/change/remove behavior, rollback on conflicting legacy identities, verification before JSON retirement, source-file change protection, idempotent retry after a worker crash between commit and reply, shared-migration cancellation (including retaining and retrying the JSON source after the final waiter cancels), cancellation during worker startup, caller cancellation and restart, SQLite busy error classification, a redacted diagnostic event, online backup/restore from a WAL database, and fail-closed handling for a future schema version.
- The Electron E2E starts the compiled storage utility process, imports and reads a host identity through its real protocol, checks graceful shutdown, and opens the resulting database read-only to verify the stored identity and schema.

## Limits

`node:sqlite` is a Release Candidate API in the pinned Electron 45 runtime line. Its calls remain confined to the storage utility process and Electron runtime startup is covered by Windows E2E. Corrupt-page recovery is not implemented or verified and must be addressed before catalog migration acceptance. Session/folder CRUD, folder-cycle detection, search/favorites, settings commands, application backup/restore UI, and catalog UI remain planned. The OpenSSH protocol fixture remains skipped, so the SSH path is still not acceptance-verified. Storage diagnostics publish static redacted events only; persistent logging remains opt-in work.
