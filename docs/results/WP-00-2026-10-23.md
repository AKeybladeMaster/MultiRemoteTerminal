## Failures reproduced and fixed

1. `pnpm install` rejected ignored build scripts: pnpm 12 uses `allowBuilds`, not the old `onlyBuiltDependencies` setting. Only reviewed esbuild is allowed; unknown install scripts remain denied. Current Electron downloads its binary explicitly or on first launch.
2. `pnpm typecheck` found project build-info collisions and cross-project path rewrite incompatibility: declaration-only project checks now have separate output/state; runtime compilation separately rewrites extensions with a shared source root. CSS ambient types and test environment typing were corrected.
3. Windows launch test timed out: minimal CJS and ESM probes showed top-level `await app.whenReady()` prevents readiness under pinned Electron 45. Startup now attaches a readiness callback. Original full E2E test passes, with sandbox preserved. Debug probes and instrumentation were removed.
4. Keyboard skip-link navigation initially caused later status refresh to fail: fragment changes are now accepted within the exact trusted document; other documents, queries, origins and foreign frames remain rejected. Unit and real keyboard/E2E regression pass.
5. Playwright waited on a cancelled navigation even though Electron retained the original document. The security assertion now inspects the retained document via Electron, confirms URL and heading, and leaves navigation denial intact.
