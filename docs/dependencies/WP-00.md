Host Node is pinned to the installed `24.14.1` for reproducibility; Node 24 is an LTS line ([official release status](https://nodejs.org/en/about/previous-releases)). This does not assert that the host patch is the newest security patch. Upgrade and rerun compatibility checks before release. Electron's embedded Node and module ABI differ from host Node: inspected ABI is **150**. WP-00 uses no native Node addons, so no node-pty/SQLite ABI compatibility claim is made.

Electron binary SHA-256 inspected locally: `8e84549b05d27d444da2957653200d1e0ac287eff0fc5722b92835b9e0821a59`. Upstream downloader performs archive checksum validation. Windows Authenticode inspection of this development executable returned NotSigned; a signed/verified packaging decision remains a release blocker. No installer or release binary is distributed in this slice.

Security scan: `pnpm audit --audit-level=high` reported **No known vulnerabilities found** on 2026-10-23. This is registry-advisory coverage, not a guarantee about all Chromium/Electron/runtime vulnerabilities. Re-scan every release. Maintenance dates for directly selected active tools were verified in registry metadata; direct versions are not deprecated. Minimum dependency publication age is 1 day, strict build allowlist and frozen lockfile are used. Third-party downloads and the Electron runtime need network access at initial setup.

[Initial CycloneDX inventory](wp-00-sbom.cdx.json) records installed development and runtime npm packages and SPDX expressions. Regenerate with `pnpm dependencies:inventory`. It is not a distribution SBOM: Electron/Chromium bundled notices, all platform variants, installer content and signing artifacts still require release inventory. Do not bundle reference-product artifacts or GPL/LGPL providers based on this development inventory.

CI actions are from their official upstream repositories: [checkout](https://github.com/actions/checkout), [setup-node](https://github.com/actions/setup-node), [upload-artifact](https://github.com/actions/upload-artifact). Versions v4.3.1/v4.4.0/v4.6.2 were resolved with `git ls-remote` and pinned by full commit SHA; upstream licenses are MIT. CI has read-only repository permissions.

REA research is separate tooling, not an application dependency: `rea-agents@6.4.0`, MIT, supported installed Node range, npm unpacked size 7,776,450. Its archive inventory is retained separately and contributes no app code or assets.
