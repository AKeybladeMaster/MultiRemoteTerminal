# WP-03 storage runtime review

**Decision date:** 2026-10-23
**Runtime:** pinned Electron 45.0.0 / Node 24.22.0 inside Electron; developer Node 24.14.1

WP-03 uses the built-in `node:sqlite` API only inside its dedicated Electron utility process. No npm dependency, native addon, npm license obligation, package update surface or package-size increase was introduced. The database connection is not opened in Electron main or the renderer.

The [Node.js v24 SQLite documentation](https://nodejs.org/download/release/v24.20.0/docs/api/sqlite.html) marks the API Stability 1.2 (Release Candidate) and records that this status began in v24.15.0. The [Electron 45 release announcement](https://www.electronjs.org/blog/electron-45-0) identifies its embedded runtime as Node 24.22.0. The local Node 24.14.1 runtime also exposes `node:sqlite`, with an experimental warning; exact Electron runtime execution is therefore covered by a Windows utility-process E2E test.

The built-in driver removes a separate native ABI and supply-chain dependency. Its Release Candidate status remains a maintenance and compatibility risk: pin Electron 45.0.0, keep SQLite access in the worker, and repeat the runtime smoke and migration tests before Electron upgrades. The application does not load SQLite extensions. The SQLite database contains metadata and public host keys only; secrets remain in the existing credential vault.
